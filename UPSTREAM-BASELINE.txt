How this fork relates to it
---------------------------
Lantern began as a copy of the baseline tree. The changes applied on top of it fall into
three groups, itemised in FORK-CHANGES.md:

1. Mechanical rename: identifiers, namespaces, project names, assembly names, asset file
   names, environment variable prefixes, data directory names, registry keys and the
   installer identity. No logic changed in this pass.
2. Identity removal and replacement: the upstream update signing key, the upstream
   Authenticode publisher and issuer, the upstream repository URL, the vendor name and the
   installer GUID were all replaced or emptied. See FORK-CHANGES.md for the rationale; the
   point is that no artifact of this fork can be mistaken for, overwrite, or be updated by
   an installation of upstream Filee.
3. Original work: the conversion policy engine under src/Lantern.Core/Policy/, its tests
   under tests/Lantern.Core.Tests/Policy/, and this documentation set under EVIDENCE/.
   These files have no upstream counterpart. EVIDENCE/ORIGINALITY.md explains how to verify
   that claim mechanically.
